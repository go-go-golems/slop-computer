---
title: The page that isn’t an artifact
date: 2026-10-24
tags: [workshop]
author: Manuel
summary: Everything on slop.computer is an artifact, except one page that can never break.
---
If every screen is an artifact, a bad push to the home screen could lock us out of the tool we would use to fix it.

So there is one page the server renders itself, at **/_/**. It can sign you in, list the routes, point any of them at an earlier version and revoke tokens. Nothing else. It is the part of the building with the fuse box.
